# Documentation index

`ARCHITECTURE.md` is retained as a compatibility index. It is no longer the
primary canonical source and must not accumulate phase history.

The reference set is:

- [canon](./canon.md) — durable product, domain, engine, architecture, and UI
  invariants;
- [current canon](./current_canon.md) — currently implemented behavior,
  active trajectory, and temporary constraints;
- [current plan](./current_plan.md) — validated baseline and ordered remaining
  lots.

Read them in that order when opening a new implementation chat. Historical
audits and specialized decision records may provide provenance, but when they
conflict with this reference set or the validated current code, they are not
the active source of truth.
